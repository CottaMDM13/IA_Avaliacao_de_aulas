# iapd - Video Lesson Analyzer

Este projeto analisa aulas gravadas em vídeo, avaliando critérios como qualidade técnica, linguagem corporal, tom de voz, clareza do roteiro, ritmo, didática e qualidade geral.

## Pré-requisitos
- Python 3.8+
- Dependências: `pip install -r requirements.txt`
